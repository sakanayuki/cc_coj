# CODE OF CLONE

CODE OF JOKER（ver1.0）の基本対戦ルールを参考に再現した、非公式ファンメイドのデジタルカードゲームです。
ブラウザのみで動作する完全静的サイトで、**GitHub Pagesでそのまま公開できます**。
対戦は **P2P（WebRTC）** 方式で、ホストが発行したIDを相手に直接伝えてマッチングします。

> 本作はファンメイドの非商用プロジェクトです。SEGA社の画像・カード名・ロゴ等の素材は一切使用しておらず、カードはすべてオリジナルの創作です。

## 画面構成（6画面）

| 画面 | 内容 |
|---|---|
| タイトル | メニュー（対戦 / デッキ構築 / 遊び方） |
| 遊び方 | ルール説明 |
| デッキ構築 | 全46種のカードプールから40枚デッキを作成・保存（localStorage）。プリセットデッキ4種付き |
| マッチング | ホストが6文字のIDを発行 → 相手がIDを入力して接続（PeerJS / WebRTC DataChannel） |
| 対戦 | ゲーム本編 |
| リザルト | WIN / LOSE / DRAW と戦績表示 |

## 公開方法（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. 「Build and deployment」で **Deploy from a branch** を選択
3. 公開したいブランチと `/(root)` を選んで保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でプレイ可能

ビルド不要（素のHTML/CSS/ES Modules）。外部依存はCDNの PeerJS のみです。

## 対戦方法

1. 両プレイヤーがサイトを開き、「対戦する」→ 名前とデッキを選択
2. ホスト側：「IDを発行して待つ」→ 表示された6文字のIDをチャット等で相手に伝える
3. ゲスト側：IDを入力して「接続する」
4. 接続が確立すると自動で対戦開始（マリガン → ターン1）

シグナリングにはPeerJSの公開ブローカーを使用し、接続確立後はブラウザ同士の直接通信になります。
ゲームロジックはホスト側が権威的に実行し、ゲストの操作はホストが検証します（相手の手札・伏せカード・山札は隠した状態だけを送信）。

## 実装しているルール

- ライフ7。0になったら敗北
- CPは自分のターン開始時に全回復し、上限が1ずつ増加（初手ターン2、最大7）
- 毎ターン2枚ドロー。手札上限7枚（超過分は捨札へ）
- フィールド最大5体、トリガーゾーン最大4枚
- ユニットは召喚ターンにアタック不可（ブロックは可）。【スピードムーブ】と進化ユニットは即アタック可
- 行動権：アタック / ブロックで消費、自ターン開始時に回復
- 戦闘はBP比較で勝敗。敗者は破壊、同値は相打ち。勝者はLVアップ（+1000、最大LV3）しBPダメージ回復、LV3到達時は行動権も回復
- ブロックされないアタックは相手ライフに1ダメージ
- オーバーライド：手札の同名カードを重ねてLVアップ＋1枚ドロー
- 進化ユニット：自分のユニットに重ねて召喚、行動権を引き継ぐ
- トリガー / インターセプトのトリガーゾーン運用
- 対戦開始時のマリガン（何度でも引き直し可、両者確定で開始）
- 各プレイヤー10ターン制。後攻が10ターン目を終えて決着しない場合は
  ライフが少ない方の敗北（同値は後攻の勝ち）

### 原作からの主な簡略化

- インターセプトは「条件成立かつCPが足りるとき自動発動」（原作は任意発動）
- 効果の対象は自動選択（ランダム / BP最大 / BP最小など）
- ジョーカーゲージ・ジョーカー能力は未実装
- 制限時間なし（10ターン上限によるライフ判定のみ）
- ホスト権威方式のため、ホスト側の改造に対する耐性はありません（身内対戦向け）

## 開発

```bash
# ローカル実行（ES Modulesのため要HTTPサーバー）
python3 -m http.server 8000
# → http://localhost:8000

# エンジンの自動テスト（カード検証＋ランダム対戦300戦）
node test/engine.test.mjs
```
